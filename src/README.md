# Source Code (`/src`)

This folder contains the complete source code for the **Campus Issue Reporting and Resolution System (CIRRS)** built using **React.js** and **Firebase**.

## Directory Layout (Planned)
```
/src
 ├── assets/          # Static images, icons, and branding
 ├── components/      # Reusable UI components (Navbar, Sidebar, IssueCard, Modal)
 ├── context/         # AuthContext and State Management
 ├── firebase/        # Firebase configuration and Firestore helper functions
 ├── pages/           # Page components (Login, Dashboard, ReportIssue, AdminPanel)
 ├── styles/          # Modular CSS and design tokens
 ├── App.js           # Main application routing and context provider
 └── index.js         # React entry point
```
