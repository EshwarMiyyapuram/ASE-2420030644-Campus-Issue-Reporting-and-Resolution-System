# Reports & Review Deliverables (`/reports`)

This folder contains formal capstone project progress reports, review slides, and evaluation deliverables submitted for **Engineering Capstone Project – 1**.

## Deliverables & Review Phase Milestones
- **Review-1 (Phase 1)**: Abstract Submission, Team Registration & Repository Setup (`review-1`).
- **Review-2 (Phase 2)**: Prototype UI, Mid-term Evaluation & Firebase Integration (`review-2`).
- **Final Review (Phase 3)**: Final Codebase, Complete Testing & Final Project Report (`final`).
