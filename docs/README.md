# Documentation (`/docs`)

This folder contains project documentation, design documents, architecture diagrams, and abstract files for the **Campus Issue Reporting and Resolution System (CIRRS)**.

## Included Files
- `Project_abstract.docx` - Original abstract submission document (Word format).
- `ASE_Project_Abstract.pdf` - Original abstract submission document (PDF format).

## Contents
- **System Architecture**: Documentation on React.js frontend architecture and Firebase (Firestore & Auth) backend structure.
- **Workflow & Sprint Planning**: Iterative sprint plans following Adaptive Software Engineering methodology.
